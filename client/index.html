รายละเอียดโมดูล: ระบบคำนวณและติดตามการผ่อนสินค้า (Product Installment) ผ่อนสินค้า

หน้านี้ใช้สำหรับ **คำนวณและสร้างตารางผ่อนชำระสินค้า** (เช่น โทรศัพท์มือถือ เครื่องใช้ไฟฟ้า หรือยานพาหนะ) สามารถระบุราคาสินค้า เงินดาวน์ ค่างวดต่อเดือน และวันที่เริ่มผ่อน เพื่อสร้างตารางตัดงวดแบบ Real-time

• ยอดหลังดาวน์: ราคาสินค้า - เงินดาวน์
• ตัดงวดอัตโนมัติ: เปลี่ยนสถานะงวดเป็น "ชำระแล้ว" เพื่อหักยอดคงเหลือ
• บันทึกชื่อชัดเจน: ระบุชื่อลูกค้าและชื่อผู้บันทึกข้อมูลทุกรายการ

รายละเอียดโมดูล: ระบบบันทึกสินเชื่อธนาคาร / หนี้รายเดือน (Bank & Monthly Loan) สินเชื่อธนาคาร

หน้านี้ใช้สำหรับ **บันทึกข้อมูลสินเชื่อสถาบันการเงิน สินเชื่อบ้าน รถ หรือบัตรเครดิต** ที่คิดดอกเบี้ยแบบรายปี หรือลดต้นลดดอก เพื่อส่งจัดเก็บเข้าสู่ระบบ Google Sheets อย่างเป็นระบบ

• อัตราดอกเบี้ยต่อปี (%): คำนวณอัตราดอกเบี้ยตามสัญญาเงินกู้
• ระยะเวลากู้ (ปี): คำนวณระยะเวลาผ่อนชำระทั้งหมด
• ซิงค์ Google Sheets: บันทึกลงตาราง Installments / Loans

สินเชื่อธนาคาร / หนี้รายเดือน (ลดต้นลดดอก)

รายละเอียดโมดูล: คลังประวัติและจัดการข้อมูลทั้งหมด (Data History Center) ประวัติข้อมูล

หน้านี้ใช้สำหรับ **เรียกดู ตรวจสอบ และจัดการประวัติรายการบันทึกหนี้สินทั้งหมด** ทั้งกู้รายวัน ผ่อนสินค้า และสินเชื่อธนาคาร ข้อมูลถูกผูกด้วยรหัส Unique ID (UUID) ระบุชื่อลูกค้า และชื่อผู้บันทึกไว้อย่างสมบูรณ์

• Unique ID: ป้องกันข้อมูลซ้ำซ้อนในระบบ
• ระบุผู้ทำรายการ: สามารถตรวจสอบได้ย้อนหลังว่าใครเป็นผู้บันทึก
• ลบข้อมูล: รองรับการลบรายการเดี่ยวและการล้างแคชเครื่อง

ประวัติรายการทั้งหมดในระบบ

ID รายการ วันที่บันทึก ประเภท ชื่อลูกค้า / ผู้ผ่อน รายการ / สินค้า ยอดรวม (บาท) ผู้บันทึก จัดการ

ตั้งค่าการเชื่อมต่อ Google Sheets API

นำ Google Apps Script Web App URL มาวางที่นี่เพื่อบันทึกและดึงข้อมูลกลับมาแสดงผลโดยอัตโนมัติ

โครงสร้างชีตที่ระบบจัดเก็บให้อัตโนมัติ:

  • Customers: รายชื่อและประวัติลูกค้า
  • Installments: รายการผ่อนสินค้าและหนี้สิน
  • Payments: ประวัติการตัดงวดเงิน
